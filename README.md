# 💰 Finance Tracker

A web-based Personal Finance Tracker that helps users manage their income and expenses and keep track of their finances.

## ✨ Features

- User Registration and Login
- Add Income and Expenses
- Automatic Balance Calculation
- Transaction History
- Delete Transactions
- Dashboard Summary
- SQLite Database Integration

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** SQLite

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/snehapradhan765-del/finance-tracker.git
```

### 2. Navigate to Backend

```bash
cd finance-tracker/Backend
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file using `.env.example` and set your secret key.

### 5. Run the Backend

```bash
python app.py
```

### 6. Open the Frontend

Open `Frontend/login.html` using VS Code Live Server.
